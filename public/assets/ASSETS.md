# Furniture assets

`furniture.glb` is generated by the original Blender Python script at
`scripts/build_furniture.py`. It contains no downloaded furniture meshes,
photographs, image textures, or source geometry from the reference repository.
The shapes are approximate visual interpretations, not measured room scans.

## Rebuild

From the project directory, either use an installed Blender:

```sh
blender --background --factory-startup --python scripts/build_furniture.py
```

Or use the official Blender Python wheel on a supported Python/platform:

```sh
uv run --python 3.11 --with bpy==4.5.15 python scripts/build_furniture.py
```

The Python wheel and its dependencies are build tools; they are not shipped to
the browser. Blender's GLTF exporter writes the binary GLB directly to
`public/assets/furniture.glb`.

## Runtime contract

There are nine independently cloneable root groups, named exactly:

- `bed`
- `wardrobe`
- `desk`
- `chair`
- `floor-bed`
- `pedestal-fan`
- `stool`
- `plant`
- `shelf`

Each group's geometry is normalized to **one unit in width, depth and height**,
with a **bottom-center origin**. GLTF uses Y-up; the normalized bounds are
X `[-0.5, 0.5]`, Y `[0, 1]`, and Z `[-0.5, 0.5]`. Set the root's scale to
`(item.width, item.height, item.depth)` in a Y-up renderer, then set the item's
floor position and yaw. Normalization is baked into mesh vertices, leaving the
root's scale as identity. The bed frame, bedding and pillows remain children
of the bed group.

Root extras record `kind`, nominal `sourceDimensions`, `pivot`, `units`,
`authoredWith`, `normalizedDimensions` and `meshCount`. Nominal dimensions are
authoring proportions only, not measurements of the user's belongings.

Primary recolorable materials are named `BODY_<kind>` and have
`editableColor: true` in their extras. Secondary wood, linen, pillows, hardware
and plant-pot materials retain their own colors. Mesh extras also identify
`asset_kind` and whether that mesh is `recolorable`.

The application should retain its procedural furniture fallback if GLB loading
fails. All nine furniture items remain movable and selectable as whole groups.

## Verification

Generated with the official Blender Python module **4.5.15**. The current GLB is
727,064 bytes, with 141 meshes and 17,514 exported vertices across all nine
assets. The build script checks the delivered GLB 2.0 header and file length,
exact root names, identity transforms, normalized bounds and floor contact for
every group, all nine editable materials, and absence of embedded media.
Those checks pass. Interactive loading and rendering are checked separately by
the application tests.

Desk accessories are intentionally excluded from the normalized desk asset so
the configured height refers to the desk itself. A laptop lid should not reduce
the tabletop height when the furniture is resized.
